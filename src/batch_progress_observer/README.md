# Batch Progress Observer

## テーマ

複数の処理を順番に実行する、簡易的なバッチ処理を作ります。

バッチ処理では、実行中に次の出来事が発生します。

- バッチ処理を開始した
- 一つの処理が完了し、進捗が更新された
- すべての処理が完了した
- 処理の途中で失敗した

これらの出来事を、必要とする複数の通知先へ伝えられるようにします。通知先は実行前に追加でき、不要になった通知先は取り外せるものとします。

通知を受けた側では、例えば次のような処理を行います。

- 現在の進捗を表示する
- 発生した出来事を履歴として記録する
- バッチ処理の完了を記録する
- 失敗した処理と原因を記録する

通知先が増減しても、バッチ処理そのものは変更せずに利用できるようにします。実際のメール送信、外部通信、並列処理は行いません。
