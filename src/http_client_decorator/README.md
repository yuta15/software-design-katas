# HTTP Client Decorator

## テーマ

簡易的なHTTPクライアントへ、必要に応じて機能を組み合わせて追加できるようにします。

HTTPクライアントは、リクエストを受け取ると、あらかじめ設定されたレスポンスを返すか例外を送出します。実際の外部通信は行いません。

このクライアントへ、次の機能を追加します。

- リクエストの開始、成功、失敗を記録する
- 一時的な失敗が発生した場合に再試行する
- 同じGETリクエストのレスポンスを再利用する（発展）

これらの機能は単独でも複数でも利用でき、組み合わせる順番も変更できるようにします。利用側は、どの機能が追加されているかにかかわらず、同じ方法でHTTPクライアントを利用できるものとします。

実装後は、機能を組み合わせる順番によってログの回数やキャッシュ時の処理がどう変わるか確認します。
